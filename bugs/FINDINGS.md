# Findings

This file lists the 42 bug records in this directory, generated by `scripts/findings.py`. Every record is a property that was refuted on the Lean model and then confirmed on NumPy 2.5.4. Each one has a reproducer in `repro/` that prints `REPRODUCED`, and `scripts/check_bugs.py` reruns all of them. Behaviour that the NumPy documentation already warns about is recorded as a refuted property in the Lean files and is not listed here.

By severity there are 4 high, 15 medium and 23 low records. By area the counts are Broadcast 5, DType 2, Datetime 7, Indexing 10, IntArith 1, LibInt 8, NpyFormat 4, Shape 1, Strings 4.

None of these has been reported to NumPy, and the `upstream` field of each record says whether an existing issue was searched for.
