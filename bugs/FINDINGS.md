# Findings

This file lists the 55 bug records in this directory, generated by `scripts/findings.py`. Every record is a property that was refuted on the Lean model and then confirmed on NumPy 2.5.4. Each one has a reproducer in `repro/` that prints `REPRODUCED`, and `scripts/check_bugs.py` reruns all of them. Behaviour that the NumPy documentation already warns about is recorded as a refuted property in the Lean files and is not listed here.

By severity there are 5 high, 18 medium and 32 low records. By area the counts are Broadcast 10, DType 4, Datetime 7, Indexing 10, IntArith 1, LibInt 10, NpyFormat 8, Shape 1, Strings 4.

None of these has been reported to NumPy by this project. On 12 November 2026 every record was searched for in the open and closed issues and pull requests of numpy/numpy, and the cited code was compared with NumPy main. The verdict is in the `upstream` field of each record and in the tables below. NEW means no issue or pull request describes the bug and main still has the code. RELATED means similar reports exist but none describes this bug. KNOWN-OPEN and KNOWN-CLOSED mean an open or closed issue or pull request covers it. FIXED-ON-MAIN means NumPy fixed it after 2.5.4.

By verdict there are NEW 26, RELATED 13, KNOWN-OPEN 7, KNOWN-CLOSED 2, FIXED-ON-MAIN 7.
